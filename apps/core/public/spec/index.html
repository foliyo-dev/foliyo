Foliyo Resume Spec

Structured, portable resumes — JSON data, .fio packages, and optional ATS status updates. Hosted under foliyo.dev.

What it is

  • Data spec — machine-readable resume JSON (no PDF parsing)
  • File format — .fio ZIP with signature
  • Status API — ATS notifies candidates of application progress

Naming

  • Spec: Foliyo Resume Spec (foliyo/resume v0.1)
  • Extension: .fio
  • Schema: https://spec.foliyo.dev/resume/v1

Unrelated to the FOLIO library services platform (folio.org).
